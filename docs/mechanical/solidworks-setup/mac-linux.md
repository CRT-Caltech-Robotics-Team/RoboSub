# Solidworks Setup for Mac / Linux

**Author**: Steven Lei

**Last updated**: 10/17/26


**NOTE**: There is currently no native support for Solidworks via Mac or Linux.

However there are two known work arounds -

1) Remote access into a Windows machine running Solidworks via Parsec (for Linux, supported on major distros like Arch, Ubuntu, Fedora)

2) Create a virutal Windows machine using Parallels (Mac only + cost money)

There are other options as well, but not known to be reliable/easy to use
for most people.


Our recommendation is to Parsec into the CRT Workstation. Note that only one
person will be able to use the computer at a time, so you will have to share.

## Parsec Setup (Mac / Linux)

Parsec is a remote sharing application between computers. Originally intended
for gaming, it has grown to be reliable for purposes like these such as using
Windows machines for remote work. Think of it as a screen sharing service but
you also have keyboard and mouse control as well.
