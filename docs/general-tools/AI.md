## LLM Providers

As of FA 2026 the following providers offer limited / free / student subscrpitions:

* [Gemini](https://gemini.google/students/)

* [OpenAI](https://chatgpt.com/students/2026/)

Good to use but not free currently

* Anthropic (Claude)

* Cursor

*Avoid using Grok, GitHub/Microsoft Copilot*. These providers are currently not good enough and you'd have better luck making dummy ChatGPT accounts.

If you're interested, locally hosted models: Ollama is reputable and okay. Can also check out the [leaderboard](https://onyx.app/self-hosted-llm-leaderboard). Set these up to your own avail.
